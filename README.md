## 🌟 Features & Interactive Views

1. **Introduction & Cosmic Overview (సృష్టి విజ్ఞానం)**
   - Vedic creation stages from *Srimad Bhagavatam* (Canto 2 & 3).
   - Comparative timelines across Yugas and Kalpas.

2. **Brahma & Divine Family Genealogy (చతుర్ముఖ బ్రహ్మ & దివ్య వంశవృక్షం)**
   - Lineages of Brahma, Kashyapa, Daksha, Adityas, and Vedic Rishis.
   - Interactive zoomable family tree views.

3. **Srimad Bhagavatam Tree (శ్రీమద్భాగవత వంశవృక్షం)**
   - Comprehensive tree view mapping incarnations, kings, and sages with portraits and scriptural references.

4. **Vedic & Itihasa Chronology (వైదిక కాలగణనం & ఇతిహాసాలు)**
   - Detailed timeline from Satyayuga down through Kaliyuga, Mahabharata war, and Bhagavad Gita chapters.

5. **5000 Years of Indian History (5000 ఏళ్ల భారతీయ సమగ్ర చరిత్ర)**
   - Indus Valley & Saraswati-Sindhu civilization, Maurya, Gupta, South Indian Dynasties (Chola, Pandya, Chalukya, Vijayanagara), down to Modern India.
   - Ancient Indian Sciences, Universities (Takshashila, Nalanda), and Mathematicians.

6. **Bilingual Experience & Sacred Audio**
   - Seamless toggle between **Telugu (తెలుగు)** and **English**.
   - Integrated meditative sound player and search system.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: GitHub Pages via GitHub Actions

---

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/brkragents-arch/Sanatana-Bharat.git
cd Sanatana-Bharat
npm install
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```

---

## 🌐 Deployment to GitHub Pages

This project is configured with GitHub Actions to automatically build and deploy to GitHub Pages upon pushing to the `main` branch.

In the repository settings on GitHub:
1. Go to **Settings > Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Pushes to `main` will automatically build and publish to:
   **`https://brkragents-arch.github.io/Sanatana-Bharat/`**
